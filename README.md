# Mis Skills Repository

Repositorio centralizado para almacenar, versionar y sincronizar skills compatibles con **Antigravity (AGY)**, **OpenCode** y otros asistentes de IA basados en agentes.

## Estructura

```text
skill/
├── README.md
├── install.sh                  # Script de instalación rápida multi-plataforma
└── skills/                     # Directorio con las skills modulares
    ├── diagnose-crash/
    │   └── SKILL.md
    └── omarchy/
        └── SKILL.md
```
